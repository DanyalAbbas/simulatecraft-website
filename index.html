SimulateCraft

LLM agents that play Minecraft

One command clones SimulateCraft. Install Git + Node.js 18+ first, then add OpenRouter, 9Router, or your own API in .env.

PowerShell

irm https://raw.githubusercontent.com/DanyalAbbas/SimulateCraft/main/install.ps1 | iex

If that 503s: irm https://cdn.jsdelivr.net/gh/DanyalAbbas/SimulateCraft@main/install.ps1 | iex

Terminal

curl -fsSL https://raw.githubusercontent.com/DanyalAbbas/SimulateCraft/main/install.sh | bash

Connect an LLM

after install

Prefer OpenRouter, 9Router, or your own API. Groq works for a quick try but hits rate limits fast.

  • OpenRouter — set OPENROUTER_API_KEY in .env
  • 9Router — set OPENAI_BASE_URL, OPENAI_API_KEY, and SIMULATECRAFT_MODEL
  • Own API — any OpenAI-compatible endpoint via OPENAI_BASE_URL

Provider setup docs →

  1. Before install: Git, Node.js 18+, and Docker Desktop (for bundled Minecraft).
  2. After install: edit ~/SimulateCraft/.env, then .\run.ps1 / ./run.sh.
  3. Viewer → http://127.0.0.1:8000 · Minecraft Java 1.21.4 → localhost
